¿Cómo añadir archivos?
1. Entra en tu repositorio de GitHub.
2. Pulsa Add file → Upload files.
3. Sube los archivos a la carpeta raíz o a una subcarpeta.
4. Pulsa Commit changes.
5. Espera a que GitHub Pages publique los cambios.

Los archivos se detectan automáticamente.
